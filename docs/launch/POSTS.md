## LinkedIn

> Markets forget. I built an app that doesn't.
>
> For the Walrus x Tatum Total Recall hackathon I built Grudge. Every five and fifteen minutes it asks four voices the same question: will Bitcoin end this window higher? The voices are DeepBook (an onchain market on Sui), Polymarket, Kalshi and a crowd of visitors. When the window resolves, Grudge marks each call right or wrong, weights each voice by its record, and writes the record to Walrus Memory on mainnet.
>
> The part I wanted to prove: I wiped the server, and it rebuilt every trust weight from Walrus alone, with a difference of 0. That run is in the demo video.
>
> It learns only a little. Over the last 100 five-minute windows it scores 0.140 against 0.157 for a plain average, which is a real gain, but DeepBook on its own scores 0.139. I say so in the blog.
>
> Agents can also pay for the consensus: x402, USDC on Sui, no SUI needed, and a replayed payment is refused. Sui reads go through Tatum.
>
