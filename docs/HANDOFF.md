## Gotchas learned
- **Shell:** never put backticked words in an unquoted heredoc (`<<EOF`): bash runs them as commands. A long inline heredoc, or a long `node -e '…'` with apostrophes, failed to parse twice this session; write the script with the Write tool (scratchpad) and run it. Edit docs through a node script that normalizes CRLF (`docs/*.md` are CRLF on this machine) and asserts each replacement matched. In git-bash a bare `"/"` inside `curl -w` is rewritten to a Windows path.
- **Render:** a new `value:` env var in `render.yaml` did not reach the existing service; set it with the Render MCP `update_environment_variables` (this redeploys). `exs-…` is a Blueprint ID; `get_blueprint` lists its `srv-…`; Render MCP calls need `workspaceId`. If a push does not deploy, `list_events` shows nothing for it: the GitHub notification was lost; check the dashboard's GitHub connection before triggering a manual deploy (which also restarts the worker).
- **Claude Design** cannot open any claude.ai artifact link. Hand it files. A zip's `data/` subfolder did not come through, so upload JSON files directly. Upload set: `docs/DESIGN-BRIEF.md`, `docs/IDENTITY.md`, `docs/brand-guidelines.md`, plus fresh `GET /api/board`, `GET /api/receipts` and `POST /api/verify-memory` responses. Standalone claude.ai/design closes 2026-12-14. To view its files: copy to a scratch folder, rename `support (N).js` to `support.js`, serve with `python -m http.server`; trust a solo render and DOM measurements over element screenshots.
- **Pick cap address:** behind Cloudflare and Render the visitor is the second-to-last `X-Forwarded-For` entry (`server/caller.ts`).
- **Walrus relayer** answers a fresh process with empty recalls for its first ~2 s; `coldboot.ts` retries up to four times, 2 s apart. `recall` returns the most similar memories, not the newest, which is why records live in hourly buckets. Watch for `RECALL_TIMEOUT` (504) on large recalls.
- **x402:** gasless USDC builds and simulates through Tatum (`tx.balance` + `0x2::balance::send_funds`). JSON cannot carry bigint: amounts go out as strings. Sui public JSON-RPC is retired; use `https://graphql.mainnet.sui.io/graphql`. Headers are `PAYMENT-REQUIRED`, `PAYMENT-SIGNATURE`, `PAYMENT-RESPONSE`; the design's v1 `X-PAYMENT` does not exist.
- **Tatum:** bursts get HTTP 429, and idle connections drop; `ThrottledTransport` retries after 1 s then 3 s. Call counts reset on every deploy, so label them "since the last deploy".
- Polymarket closes a window between 80 s and several minutes after it ends (the worker asks every 20 s for up to 20 minutes); Gamma `markets?slug=` needs `&closed=true` for resolved markets. Kalshi `min_close_ts`/`max_close_ts` return exactly the window's market. DeepBook mainnet has 1m and 5m markets only.
- **Walrus look-alike values:** owner address, account object ID (`MEMWAL_ACCOUNT_ID`, public: `0x38de8cce40f73eeb500055ec3330b12fe0ad8347ee4d6fc5274ebe078bc20a04`), delegate private key, delegate public key (on-chain keys are base64, not hex).
- One env file, `.env` (gitignored). `tsx` treats `.ts` as CommonJS, so scripts are `.mts`, run with `--conditions=react-server --env-file=.env`, with relative imports. Biome formats code only (`docs`, `.claude`, `*.md` excluded); `pnpm exec biome check --write` fixes formatting. pnpm holds back packages published in the last 24 hours; three Mysten versions are excluded in `pnpm-workspace.yaml`. With `@playwright/test` installed Biome also applies Playwright rules, so do not name a function `describe`.
- **UI dev server:** `GRUDGE_WORKER=off pnpm dev --port 3100` still points at the production database, and from the owner's machine `/api/board` takes 3 to 6 s (production answers in 0.3 to 2.8 s). **Never POST `/api/pick` against it** (it would add a real Crowd call); intercept the route.
- **Next route files:** a file named `layout.ts`, `page.tsx` and so on inside `src/app/` is treated as a route file (a `layout.ts` broke the typecheck; the hook is `breakpoint.ts`). `pnpm dev` also writes an untracked `AGENTS.md` in the repo root; delete it.
- **Fonts and lint:** Martian Mono has no ▲ or ▼, so use `<Arrow />` (`marks.tsx`) at display sizes. `font-stretch` maps to its width axis through `next/font` (`axes: ["wdth"]`). Tailwind's reset removes link underlines; `globals.css` restores them. Biome's `useSemanticElements` rejects ARIA roles on divs, so the ledger is a native `<table>` and the confidence choice is native radios; `noDescendingSpecificity` wants lower-specificity CSS rules first.
- **Testing the UI:** the Playwright MCP browser can be locked by a stale process; fall back to `npx -y playwright screenshot --full-page --viewport-size=W,H --wait-for-timeout=9000 URL out.png`, or a script using `playwright-core` from the scratchpad. To test states, serve a saved real `/api/board` response from `page.route`, mutating it (`locked: null`, `workerAgeMs: 120000`, a fresh `open` window with `lockAt` in the future, `ledger[0].state: "void"`). Lighthouse: `npx lighthouse URL --only-categories=… --chrome-flags="--headless=new --no-sandbox"` with `CHROME_PATH` set to the cached chromium; `impeccable detect <url>` runs the page-level checks the file scan skips. Tests of app code need the `@` alias, in `vitest.config.mts`.
